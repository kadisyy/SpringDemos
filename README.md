# SpringDemos

## 项目简介 / About

**SpringDemos** 是一个基于 [Spring Framework](https://spring.io/) 的示例代码合集，旨在通过一系列可运行的小型工程，帮助开发者快速学习和理解 Spring 生态中的核心概念与常用功能。

**SpringDemos** is a collection of sample projects built on the [Spring Framework](https://spring.io/). Each module is a self-contained, runnable demo that illustrates a key concept or commonly used feature of the Spring ecosystem, making it easier for developers to learn and get started quickly.

---

## 项目用途 / Purpose

- 📖 **学习参考**：每个子模块聚焦一个独立的知识点（如 IoC/DI、AOP、Spring MVC、Spring Boot、Spring Data JPA 等），方便按需查阅。
- 🚀 **快速上手**：提供最简可运行的代码示例，帮助你在最短时间内理解某个特性的用法。
- 🧪 **实验场**：可在此基础上自由修改、扩展，验证自己的想法和方案。

- 📖 **Learning reference**: Each sub-module focuses on a single topic (e.g. IoC/DI, AOP, Spring MVC, Spring Boot, Spring Data JPA, etc.) so you can look up exactly what you need.
- 🚀 **Quick start**: Provides minimal, runnable code examples to help you understand a feature as fast as possible.
- 🧪 **Sandbox**: Freely modify and extend the demos to experiment with your own ideas.

## 环境要求 / Prerequisites

- **JDK** 8 或以上 / JDK 8 or above
- **Maven** 3.6+ 或 **Gradle** 6+
- 推荐使用 IntelliJ IDEA 或 Eclipse 导入工程 / Recommended IDE: IntelliJ IDEA or Eclipse

---

## 快速开始 / Quick Start

```bash
# 克隆仓库 / Clone the repository
git clone https://github.com/kadisyy/SpringDemos.git
cd SpringDemos

# 进入某个示例模块，使用 Maven 运行 / Enter a demo module and run with Maven
cd <module-name>
mvn spring-boot:run
```
