# SpringDemos

> **这个工程有什么用？**
>
> SpringDemos 是一个 Spring 生态系统的示例代码集合，旨在通过可运行的示例帮助开发者快速学习和掌握 Spring 框架的核心功能与最佳实践。

---

## 项目简介 / Project Overview

**中文：**
SpringDemos 是一个面向 Java 开发者的学习型项目，涵盖 Spring Boot、Spring MVC、Spring Data、Spring Security 等主流 Spring 组件的典型用法示例。每个示例均为独立、可运行的 Demo，方便开发者按需参考和学习。

**English：**
SpringDemos is a learning-oriented project for Java developers, covering typical usage examples of mainstream Spring components such as Spring Boot, Spring MVC, Spring Data, and Spring Security. Each demo is standalone and runnable, making it easy to reference and learn from.

---

## 技术栈 / Tech Stack

- Java 8+
- Spring Boot
- Spring MVC
- Spring Data JPA / MyBatis
- Spring Security
- Maven / Gradle

---

## 主要用途 / Main Use Cases

1. **快速上手 Spring Boot**：了解如何用 Spring Boot 搭建 RESTful API、配置数据源、整合常用中间件。
2. **学习 Spring MVC**：掌握控制器、请求映射、参数绑定、异常处理等核心概念。
3. **数据访问层示例**：演示如何使用 Spring Data JPA 或 MyBatis 进行数据库 CRUD 操作。
4. **安全认证**：展示 Spring Security 的基本配置与 JWT 鉴权流程。
5. **常用设计模式与最佳实践**：结合 Spring 框架演示 AOP、事务管理、缓存等高频场景。

## 快速开始 / Quick Start

```bash
# 克隆仓库
git clone https://github.com/kadisyy/SpringDemos.git
cd SpringDemos

# 使用 Maven 构建并运行
mvn spring-boot:run
```

> 各子模块的详细运行说明请参考对应目录下的 `README.md`。
